# MainStory
전체적인 게임의 스토리를 서술합니다.
LLM은 메인스토리를 기반으로 게임의 설정 및 방향성을 지정할 수 있습니다.

```
여기에 메인 스토리를 작성해주세요
```

### Chapter
메인스토리가 게임의 전반적인 방향성을 정한다면 챕터에서는 게임 스토리의 디테일을 담당합니다.
하단의 하위챕터들로 구성되며 마지막 챕터만 FINAL로 지정하면됩니다.

각 챕터들은 목표: 로 시작하는 타겟이있으며, 이 조건을 만족할경우 다음 챕터로 진행하게됩니다.
LLM은 챕터에 작성된 스토리를 보고 퀘스트를 자율생성하고, 마지막 퀘스트는 목표와 관련된 퀘스트를 작성합니다.

#### 1
목표:[몬스터:이름]을 [처치]
```
여기에 챕터의 스토리를 작성해주세요
```
#### 2
목표:[아이템:이름]을 [획득]
```
여기에 챕터의 스토리를 작성해주세요
```
#### 3
목표:[마스터자율]
```

```
